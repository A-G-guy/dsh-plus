# ui-mobile-fit 上游跟进记录

记录每次 dsh 升级时对官方客户端 UI 结构（CSS Modules 局部名、data 钩子、交互结构）
的复核结论与本插件的锚点动作。现行选择器稳定性策略与复核步骤见
[README](README.md) 的「选择器稳定性策略」。

复核前提：上游语义后缀**不随版本重命名**是假设而非保证——历史上发生过
`_detailsCol` → `_rightbarCol` 这类更名，旧名会静默失效且无任何告警。因此每次升级
都必须按 README 的复核步骤把全部 `class*="_x"` 与 `[data-*]` 在官方安装树里逐一检索，
并对每条规则判定「仍需要 / 上游已实现（删）/ 死选择器（改锚或删）」。

新版本追加在表末；已有条目只增不改，结论修正时新开条目并引用旧条目。

| 上游版本 | 变化 | 本插件动作 |
|---|---|---|
| 0.2.1-alpha.1 | 选择器全量复核（工具卡 `_ioCard/_ioText/_codeBody/_terminalBody/_diffBody`、会话头 `_titleRow/_headerUtilities/_headerActions/_crumbs`、composer `_composerStack/_composerSeat/_composerHero/_tools/_modes/_accessory`、布局 `_frame/_sidebarCol/_centerCol/_rightbarCol/_handle/_toggle/_railMark/_panelIcon`、覆盖层 `_overlay/_overlayLayer/_panel/_nav/_navList/_content/_bubble/_deleteDialog/_fetchDialog/_modelField/_modelRow/_modelCatalog/_modelList/_row/_rowText/_selector`、markdown `_markdown`）全部命中；data 钩子（`data-sidebar-collapsed`/`data-rightbar-collapsed`/`data-sidebar-right-open`/`data-composer-seat`/`data-plan-review-key`/`data-question-key`/`data-approval-key`）与 `input.file` 菜单行结构（`[role=option] > span._label > span._labelText`）在列 | 零死选择器，无改锚 |
| 0.2.1-alpha.1 | 上游补上了 6 处本插件原本自行兜底的声明：`_centerCol`/`_sidebarCol`/`_rightbarCol` 自带 `min-width:0`；`_crumbs` 自带 `min-width:0` + `overflow:hidden`；`_headerActions`/`_headerUtilities` 为 `flex:none`（⊇ `flex-shrink:0`）；markdown 由 primitives 的 `MarkdownText`/`CodeBlock` 模块样式覆盖 `<img>`（`max-width:100%` + `height:auto`）、表格滚动包裹层 `_tableScroll`（`max-width:100%` + `overflow-x:auto`，宽表配 `md-table-wide`）与 `_markdown .katex-display`（`max-width:100%` + `overflow-x:auto`）；`_composerHero` 为 `width:min(…, 100%)` | 删除这 6 组冗余规则（`layout.ts` 中列/右列 min-width、`conversation.ts` 的 `_crumbs`、`_headerActions/_headerUtilities`、`[class*="_markdown"] img`、`[class*="_markdown"] table`、`.katex-display` 与 composer 三件套 max-width）；`_composerStack/_composerSeat` 另因块级容器默认宽度已 ≤ 容器而一并去兜底 |

| 0.2.1-alpha.1 | composer 文件入口仍为 `+` 菜单的「文件」行（`input.file`）+ 同 composer 内无 `accept` 的隐藏 file input | 触屏二次选择层锚点不变（`[role="option"]` 行 + `readRowLabel` 取 `_labelText`，失配回退 `textContent`） |
| 0.2.1-alpha.2 | 选择器全量复核：README 列出的全部 `class*="_x"` 语义后缀与 data 钩子（`data-sidebar-collapsed`/`data-rightbar-collapsed`/`data-sidebar-right-open`/`data-composer-seat`/`data-plan-review-key`/`data-question-key`/`data-approval-key`）在官方客户端分包里仍全部命中；`input.file` 行与 `[role=option] > span._label > span._labelText` 结构不变 | 零死选择器，无改锚 |
